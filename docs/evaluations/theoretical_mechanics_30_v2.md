### 实际回答

点沿曲线运动时，加速度可以分解为切向加速度和法向加速度两部分，即
\[ a(t) = \ddot{s} \boldsymbol{\tau} + \frac{\dot{s}^2}{\rho} \boldsymbol{n} \]
其中，\(\boldsymbol{\tau}\) 是轨迹的切线方向单位矢量，\(\boldsymbol{n}\) 是轨迹主法线方向单位矢量，\(\rho\) 是曲率半径，\(s\) 是沿轨迹的弧长参数。

切向加速度沿轨迹的切线方向，反映速度大小对时间的变化率；法向加速度沿轨迹主法线方向，指向曲率中心，反映速度方向改变的快慢程度[1][9]。

### 实际回答

曲线上一点的曲率定义为单位弧长变化时切向量方向的变化率，即
\[ \kappa = \lim_{\Delta s \to 0} \frac{\Delta \theta}{\Delta s} = \left| \frac{d\tau}{ds} \right| \]
其中，\(\tau\)为切向单位矢量，\(s\)为弧长。曲率半径\(\rho\)定义为曲率的倒数，
\[ \rho = \frac{1}{\kappa} \]
曲率半径表示曲线在该点的“弯曲程度”的尺度，曲率越大，曲率半径越小，曲线弯曲越剧烈[1][9][10]。

### 实际回答

刚体速度投影定理的内容是：在任意时刻刚体上任意两点的速度在这两点的连线方向上的投影相等。数学表达式为
\[
v_B \cdot e_{AB} = v_A \cdot e_{AB}
\]
其中，\(v_A\)和\(v_B\)分别是刚体上两点A和B的速度矢量，\(e_{AB}\)是从点A指向点B的单位矢量。根据刚体运动的速度关系，
\[
v_B = v_A + \omega \times r_{AB}
\]
由于\((\omega \times r_{AB})\)垂直于\(e_{AB}\)，其在\(e_{AB}\)方向上的投影为零，因此两点速度在连线方向上的投影相等，即
\[
v_B \cdot e_{AB} = v_A \cdot e_{AB}
\]
这就是速度投影定理的数学表达式和内容[1][3][4]。

### 实际回答

刚体复合运动的角加速度合成公式为：
\[
\boldsymbol{\varepsilon} = \boldsymbol{\varepsilon}_e + \boldsymbol{\varepsilon}_r + \boldsymbol{\omega}_e \times \boldsymbol{\omega}_r
\]
其中，\(\boldsymbol{\varepsilon}\) 是刚体的绝对角加速度，\(\boldsymbol{\varepsilon}_e\) 是动参考系（牵连运动）的角加速度，\(\boldsymbol{\varepsilon}_r\) 是相对运动的角加速度，\(\boldsymbol{\omega}_e\) 和 \(\boldsymbol{\omega}_r\) 分别是牵连运动和相对运动的角速度。

出现叉乘项 \(\boldsymbol{\omega}_e \times \boldsymbol{\omega}_r\) 的原因是角速度的变化不仅包括两个角速度的直接变化，还包括它们的相互作用，这体现了刚体复合转动中角速度矢量的非平凡合成性质。该项反映了由于牵连运动的角速度变化对相对运动角速度方向的影响，是角速度矢量旋转的结果，属于刚体复合运动角加速度的非平行轴转动效应。

两种特殊情况：
1. 当相对运动和牵连运动都是定轴且角速度恒定时，角加速度仅为 \(\boldsymbol{\varepsilon} = \boldsymbol{\omega}_e \times \boldsymbol{\omega}_r\)；
2. 当相对运动和牵连运动都是定轴转动且两个转动轴平行时，叉乘项消失，角加速度为简单的代数和 \(\boldsymbol{\varepsilon} = \boldsymbol{\varepsilon}_e + \boldsymbol{\varepsilon}_r\)[4].

### 实际回答

平面力系平衡方程有三种形式：

1. 一矩式（标准形式）：
\[
R_x = 0, \quad R_y = 0, \quad M_{O_z} = 0
\]
其中，\(R_x\) 和 \(R_y\) 是力的合力在 \(x\) 和 \(y\) 方向的分量，\(M_{O_z}\) 是绕 \(z\) 轴（垂直于平面）的合力矩。

2. 二矩式（当 \(AB\) 连线不与 \(x\) 轴垂直时）：
\[
R = 0, \quad M_{A_z} = 0, \quad M_{B_z} = 0
\]
其中，\(R=0\) 表示合力为零，\(M_{A_z}\) 和 \(M_{B_z}\) 是分别绕点 \(A\) 和点 \(B\) 的力矩。

3. 三矩式（当点 \(A\)、\(B\)、\(C\) 三点不共线时）：
\[
M_{A_z} = 0, \quad M_{B_z} = 0, \quad M_{C_z} = 0
\]
即分别绕三点的力矩均为零。

以上三种形式均为平面力系平衡的充分必要条件，适用于不同的力系结构和分析需求[1]。

### 实际回答

约束是对质点系运动预加的限制条件，约束方程是描述这些限制条件的数学表达式，通常形式为不等式或等式，如
\[ f(t, r, v) \geq 0 \]
其中\(t\)为时间，\(r\)为位置矢量，\(v\)为速度矢量[9]。

单面约束是指约束方程为不等式约束，即约束方程形式为不等式，如
\[ f(t, r, v) \geq 0 \]
这类约束只限制质点运动的一侧，质点运动可分为无约束阶段和受约束阶段[1]。

双面约束是指约束方程为等式约束，即约束方程形式为等式，如
\[ f(t, r, v) = 0 \]
这类约束限制质点运动在等式所定义的曲面或空间内[1]。

总结：
- 约束是对质点运动的限制条件，约束方程是其数学表达式[9]。
- 单面约束为不等式约束，限制质点运动的一侧[1]。
- 双面约束为等式约束，限制质点运动在等式定义的范围内[1]。

### 实际回答

虚位移原理的内容是：具有理想约束的质点系在给定位置处于平衡的充分必要条件是主动力系在质点系的任意虚位移上所作的虚功等于零，即
\[
\sum_{i=1}^N \mathbf{F}_i \cdot \delta \mathbf{r}_i = 0
\]
其中，\(\mathbf{F}_i\)为主动力，\(\delta \mathbf{r}_i\)为虚位移。这一表达式也称为静力学普遍方程。虚位移原理是达朗贝尔—拉格朗日原理的特殊情况。虚位移原理的适用条件是系统具有理想约束，即约束反力对虚位移所作的虚功为零，约束反力不出现在方程中。对于结构，应先解除约束，将约束反力作为主动力，再用虚位移原理解题；对于非理想约束，则将该约束力作为主动力处理。数学表达式可用几何法或解析法表示，解析法形式为
\[
\sum_{i=1}^N (F_{xi} \delta x_i + F_{yi} \delta y_i + F_{zi} \delta z_i) = 0
\]
虚位移原理与平衡方程等价，且可用于求解系统的平衡位置及约束反力。 [2] [3] [7] [8]
