### 实际回答

点沿曲线运动时，其加速度可以分解为切向加速度和法向加速度两部分，表达式为
\[
a(t) = \ddot{s} \tau + \frac{\dot{s}^2}{\rho} n
\]
其中，\(\tau\)为轨迹的切线方向单位矢量，\(n\)为轨迹主法线方向单位矢量，\(\rho\)为曲率半径，\(s\)为弧长参数。
切向加速度沿轨迹的切线方向，反映速度大小对时间的变化率；法向加速度沿轨迹主法线方向，指向曲率中心，反映速度方向改变的快慢程度[1][9]。

### 实际回答

曲线上一点的曲率定义为该点处单位切向量\(\tau\)对弧长\(s\)的变化率的大小，即
\[
\kappa = \left|\frac{d\tau}{ds}\right| = \lim_{\Delta s \to 0} \frac{\Delta \theta}{\Delta s}
\]
其中\(\Delta \theta\)是单位切向量方向的变化角度。曲率半径\(\rho\)定义为曲率的倒数，
\[
\rho = \frac{1}{\kappa}
\]
曲率半径表示曲线在该点的“弯曲程度”的尺度，曲率越大，曲率半径越小，曲线弯曲越剧烈[1][10]。

### 实际回答

刚体速度投影定理的内容是：在任意时刻刚体上任意两点的速度在这两点的连线方向上的投影相等。数学表达式为

\[
\mathbf{v}_B = \mathbf{v}_A + \boldsymbol{\omega} \times \mathbf{r}_{BA}
\]

其中，\(\mathbf{v}_A\)和\(\mathbf{v}_B\)分别是刚体上两点A和B的速度，\(\boldsymbol{\omega}\)是刚体的角速度，\(\mathbf{r}_{BA}\)是从点A指向点B的位矢。由于\(\boldsymbol{\omega} \times \mathbf{r}_{BA}\)垂直于\(\mathbf{r}_{BA}\)，所以两点速度在\(\mathbf{r}_{BA}\)方向上的投影相等，即

\[
(\mathbf{v}_B \cdot \mathbf{e}_{AB}) = (\mathbf{v}_A \cdot \mathbf{e}_{AB})
\]

其中\(\mathbf{e}_{AB}\)是从A指向B的单位向量。这表明刚体上任意两点的速度沿它们连线方向的分量相等，体现了刚体的整体刚性特性[1][2][3][4][6]。

空间一般力系平衡的充分必要条件是作用在刚体上的全部力的合力为零，且对任意一点的合力矩为零。具体数学表达为：
\[
\sum_{i=1}^n \mathbf{F}_i = 0, \quad \sum_{i=1}^n \mathbf{r}_i \times \mathbf{F}_i = 0
\]
其中，\(\mathbf{F}_i\)为第\(i\)个力，\(\mathbf{r}_i\)为该力的作用点到参考点的矢量。

这对应空间一般力系的六个独立平衡方程：
\[
\begin{cases}
\sum F_x = 0 \\
\sum F_y = 0 \\
\sum F_z = 0 \\
\sum M_x = 0 \\
\sum M_y = 0 \\
\sum M_z = 0
\end{cases}
\]
其中，\(F_x, F_y, F_z\)是力的分量，\(M_x, M_y, M_z\)是力矩的分量。这六个方程相互独立，可用于求解六个未知数。

以上内容均来自教材中关于刚体平衡方程的描述[1][2]。

平面力系平衡方程有三种形式：

1. 一矩式（标准形式）：
\[
R_x = 0, \quad R_y = 0, \quad M_{O_z} = 0
\]
其中，\(R_x\)和\(R_y\)是力的合力在x、y方向的分量，\(M_{O_z}\)是关于z轴的合力矩。

\[
R = 0, \quad M_{A_z} = 0, \quad M_{B_z} = 0

其中，\(R\)是合力，\(M_{A_z}\)和\(M_{B_z}\)是关于点A和点B的力矩。

\[
M_{A_z} = 0, \quad M_{B_z} = 0, \quad M_{C_z} = 0
\]
即分别关于三点的力矩均为零。

以上三种形式分别适用于不同的力系几何条件，均为平面力系平衡的充分必要条件[1]。

\[ f(t, r, v) \geq 0 \]
其中包含时间、位置和速度等变量[9]。

单面约束是指约束方程为不等式约束，即约束方程形式为不等式，限制质点运动在某一侧，如
\[ f(t, r, v) \geq 0 \]，质点运动可分为无约束阶段和双面约束阶段[1][2]。

双面约束是指约束方程为等式约束，即约束方程为等式，如
\[ f(t, r, v) = 0 \]，限制质点运动必须满足该等式条件[1][2]。

因此，单面约束与双面约束的区分依据是约束方程是等式还是不等式，等式约束称为双面约束，不等式约束称为单面约束[1][2]。

### 实际回答

虚位移原理的内容是：具有理想约束的质点系，在给定位置处于平衡的充分必要条件是主动力系在质点系的任意虚位移上所作的虚功等于零，即
\[
\sum_{i=1}^N \mathbf{F}_i \cdot \delta \mathbf{r}_i = 0
\]
（几何法表达式），或解析法表达为
\[
\sum_{i=1}^N (F_{xi} \delta x_i + F_{yi} \delta y_i + F_{zi} \delta z_i) = 0
\]
该式也称为静力学普遍方程。虚位移原理是达朗贝尔—拉格朗日原理的特殊情况[4]。

适用条件为：
1. 系统必须具有理想约束，即约束反力不对虚位移做功[3][4]。
2. 对结构无自由度时，需要先解除约束，将约束反力作为主动力，再用虚位移原理解题[3][4]。
3. 对非理想约束，则将该约束力作为主动力处理[4]。

数学表达式为：
\[
\sum_{i=1}^N \mathbf{F}_i \cdot \delta \mathbf{r}_i = 0
\]
其中，\(\mathbf{F}_i\)为作用在第\(i\)个质点上的主动力，\(\delta \mathbf{r}_i\)为该质点的虚位移[4]。

虚位移原理的特点包括：
- 以系统为研究对象，不必将系统拆开
- 理想约束的约束反力不出现在受力分析和方程中
- 可直接应用于有自由度的机构，给出平衡时主动力之间的关系
- 对无自由度结构需释放约束，将约束反力当成主动力求解[3]

虚位移的求法有几何法和解析法，解析法通过对约束方程进行等时变分得到虚位移之间的关系[6][13]。

综上，虚位移原理为理想约束质点系平衡的判据，表达为主动力对任意虚位移的虚功为零，适用于理想约束系统，数学表达式为
\(\sum \mathbf{F}_i \cdot \delta \mathbf{r}_i = 0\)[4][3][6][13]。
