# CiteMind v0.1.4 — private tutorial trial

This patch candidate was tested with seven private tutorial PDFs totaling 222 selectable-text pages. It adds adjacent-page evidence, stronger Chinese formula-page ranking, stricter evidence instructions, and short-fragment Chinese PDF highlighting.

The focused backend suite passes 23 checks and the production frontend builds successfully. A document-scoped revision session produced three useful answers with six direct page citations, all opened in the PDF viewer.

This is not v1.0. The supplied private set did not include the required lecture/notes/paper mix, and a broad course-wide comparison session still produced weak outline citations and one incorrect synthesis. Private filenames, questions, extracted text, and chat data are excluded from the repository and release package.
